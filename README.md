# MING — workspace mirror

Read-only snapshot of the MING working material from the Kylon workspace **Success**.
Kylon is the source of truth; nothing here is edited directly.

Application code lives in separate repos:

- [zhihaofeng123-code/ming](https://github.com/zhihaofeng123-code/ming) — landing page and waitlist
- [zhihaofeng123-code/ming-daily-ritual](https://github.com/zhihaofeng123-code/ming-daily-ritual) — Today's Signal / daily ritual engine

## Layout

- `knowledge/` — shared workspace knowledge: business context, audiences, positioning, priorities, machine-readable brand system
- `brand/` — MING mark source files (SVG)
- `rooms/ming-product/` — ritual engine brief, worked example, raw outputs, dev + brand reviews, product screenshots
- `rooms/ming-research/` — competitor teardown (Co-Star, The Pattern, CHANI, Human Design), audience language research, briefs
- `rooms/ming-brand/` — identity system, landing copy, review notes, and exported assets (`v1/` = superseded first pass, `refs/` = reference boards)
